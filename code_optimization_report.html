优化概要

  • SQL 注入风险：所有 f-string SQL 改为参数化查询 + 白名单校验
  • 权限漏洞：修复 3 个接口缺少权限校验（商机恢复、跟进日志删除、合同删除关联清理）
  • 部署安全：Dockerfile 从 exec(open()) 改为 gunicorn；Nginx 添加 4 项安全头
  • 依赖完整性：requirements.txt 补全 openpyxl + gunicorn
  • 配置灵活性：CORS、SECRET_KEY 支持环境变量注入
  • 前端体验：API 超时从 10s 提升至 30s
