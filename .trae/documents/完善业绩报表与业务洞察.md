# 完善业绩报表与业务洞察

## Context（背景）

基于上一轮系统功能审计，"业绩报表"和"业务洞察"两项能力目前仅为部分具备：

**业绩报表短板**：
- Dashboard 5 张统计卡片的趋势百分比（"↑ 12% 本月"等）为**硬编码假数据**（[Dashboard.vue:9,18,27,36,45](file:///c:/Program%20Files/python/crm/frontend/src/views/Dashboard.vue#L9)）
- "待办提醒"卡片使用 **mock 数据**（[Dashboard.vue:158-163](file:///c:/Program%20Files/python/crm/frontend/src/views/Dashboard.vue#L158-L163)），未接入真实预警
- 缺少**销售预测**（基于商机 `amount × probability` 加权预测）
- 缺少**阶段转化率**分析（漏斗仅显示数量，未显示转化%）
- 缺少**团队/个人业绩对比**（仅有 Top5 排行，无横向对比图）
- 缺少**同比环比**趋势对比
- 缺少**Excel 报表导出**

**业务洞察短板**：
- 销售漏斗可点击跳转，但**未自动识别瓶颈阶段**（哪一段流失最大）
- **无自动洞察报告**（需用户主动提问 QA 或点击筛选）
- **无趋势异常检测**（如某月商机骤降的主动提示）

**目标**：新建独立的「业绩报表」页面，集中提供深度报表+洞察分析；同时修复 Dashboard 的假数据，接入真实预警。权限沿用 dashboard 模式（主任/院长看全部，普通用户看自己）。

## 实施方案

### 一、后端：新增 `reports.py` Blueprint

**文件**：`backend/routes/reports.py`（新建）
**注册**：`backend/routes/__init__.py`（已有 Blueprint 注册模式，参考 dashboard.py:237-238）

#### 1.1 销售预测接口 `GET /api/reports/forecast`
- 入参：`year`（可选，默认当前年）
- 逻辑：按 `predict_date` 月份分组，加权预测金额 = `SUM(amount × probability / 100)`
- 同时返回"已签约金额"（status='active' 且 probability=100 的商机，或关联合同总额）作对比
- 权限隔离：主任/院长看全部，普通用户按 `owner_id` 筛选
- 返回字段：`{ months: [...], forecast_data: [...], signed_data: [...], total_forecast: 1234.5, total_signed: 987.6 }`

#### 1.2 阶段转化率接口 `GET /api/reports/conversion`
- 6 阶段分段（与 Dashboard 漏斗一致）：< 30 / < 60 / < 80 / < 90 / < 100 / = 100
- 每阶段统计：`count`（商机数）、`amount`（商机金额合计，元）
- 转化率：当前阶段数 / 上一阶段数 × 100%（首阶段为 100%）
- 流失率：1 - 转化率
- 返回字段：`{ stages: [{ name, count, amount, conversion_rate, drop_rate }] }`

#### 1.3 团队业绩对比接口 `GET /api/reports/team-performance`
- 按 `owner_id` 分组，JOIN users 取 name
- 统计字段：商机数、商机金额、合同数、合同总额、回款总额、加权预测金额、转化率（签约数/商机数）
- 权限：仅主任/院长可调用（普通用户无团队视角）
- 返回字段：`{ members: [{ name, role, business_count, business_amount, contract_count, contract_amount, payment_amount, forecast_amount, win_rate }] }`

#### 1.4 同比环比接口 `GET /api/reports/trend-comparison`
- 入参：`time_range`（month/quarter/year）、`year`
- 当前周期 vs 上一周期：客户数、商机数、合同数、合同额、回款额
- 计算环比增长率 = (current - previous) / previous × 100%
- 返回字段：`{ metrics: [{ name, current, previous, growth_rate }] }`
- **此接口同时供 Dashboard 修复硬编码趋势使用**

#### 1.5 自动洞察接口 `GET /api/reports/insights`
- 基于上述数据自动生成结构化洞察列表，每条含 `type`/`severity`/`title`/`detail`/`suggestion`
- 洞察类型：
  - `bottleneck`：识别转化率最低的阶段（< 50%）作为瓶颈
  - `anomaly`：环比下滑超 20% 的指标
  - `top_performer`：团队业绩第一名
  - `risk_alert`：预测金额高但转化率低的负责人
  - `opportunity`：高概率（≥80%）但未签的商机数量
- 权限隔离：主任/院长看全部洞察，普通用户看自己相关

#### 1.6 Excel 报表导出接口 `GET /api/reports/export`
- 入参：`year`、`type`（forecast/conversion/team/all）
- 使用 `openpyxl`（合同导入 [contracts.py:277](file:///c:/Program%20Files/python/crm/backend/routes/contracts.py#L277) 已用此库）
- 生成多 Sheet 工作簿：销售预测、阶段转化、团队业绩、洞察摘要
- 返回 `send_file` 流式下载，文件名 `销售业绩报表_{year}_{timestamp}.xlsx`
- 主任/院长可导出全部，普通用户仅导出本人数据
